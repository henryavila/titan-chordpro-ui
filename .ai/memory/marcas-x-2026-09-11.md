# Marcas `x///` e lente Só letra (2026-09-11)

SoT: [`docs/MARCAS-X.md`](../../docs/MARCAS-X.md). Ponte em `AGENTS.md` §9.

## O que é

`x///` **não é letra**. É o relógio da cifra em trecho sem voz (intro, interlúdio, solo, final).

- `x` é **sempre** a cabeça do tempo.
- `/` é um tempo que **não** é cabeça. `[Cm]//` em 4/4 = 2 tempos, inclusive no fim da frase.
- Linha tocada (sem letra): as marcas **são** o tempo daquele papel.
- Cauda numa linha cantada: **soma**, não substitui a estrofe.
- `[G] [C] [D]` sem marca: a engine **não** adivinha. `lintSource` avisa.
- Rolar exige `{duration:}`. BPM sozinho não abre o gate.

## Só letra

Lente `letra`: some acordes, tab, partitura, linhas só de ritmo e as marcas das linhas cantadas. **Não reescreve o arquivo.** Não apagar `x///` do source para “limpar letra”.

## Não fazer

- Tratar `x///` / `//` como lixo visual.
- Exigir `x` em todo grupo.
- Usar cauda do verso como duração da estrofe.
- Contar `x` de TAB como marca de tempo.
- “Corrigir” `lineBeats('x///') === 3` (coluna 0) sem decisão de produto.
