Ícones da cifra — catálogo para validar

Hoje o chrome mistura glifo Unicode (◐ ○ ● ↓ ◀ ▶ ⋯), formas CSS (play/stop/tela cheia) e um único SVG Lucide (lápis de Editar). Unicode pinta peso diferente em cada fonte — por isso o lápis já saiu de ✎. A proposta: um set Lucide stroke (24×24, ponta redonda), o mesmo desenho do Editar, sem biblioteca npm — só os paths que usarmos. Clique numa opção por papel. O mock no topo atualiza. Rodapé copia o JSON.

O que está genérico. Play/stop falam player de mídia, não “a cifra anda”. ↓ é download. ◐○● são círculos. O metrônomo é um ponto. A lente é um disco pela metade.
O que eu manteria tipografia. + − de tom/capo/BPM, A− A+, × de fechar, ✓ de estado. São operadores, não pictogramas. Vão no grupo 7.
Como validar. Rec = pré-selecionado. Se discordar, clique outra. “Manter” deixa o atual. Quando fechar o conjunto, manda o JSON ou diz “aprovado como está”.

00Refrão — lado musical (aberto)

Nenhuma das opções do catálogo (Repeat / Repeat 2 / chevron) foi aceita. Repeat de Lucide é “recarregar a página”, não música. Três signos de partitura — escolhe um, ou diz outro.

A Barra de repetição |: dois pontos e a barra grossa. É o signo de “esta secção volta”.
B Letra de ensaio [R] Como as letras A, B, C no score: o refrão marcado, não “repetir”.
C Colchete de volta O 1. / 2. da partitura — “volta desta casa”.
